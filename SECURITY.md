# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |

## Reporting a vulnerability

If you discover a vulnerability, do not post details in a public issue. Report it privately through [GitHub Security Advisories](https://github.com/halqme/bundeck/security/advisories/new).

Include reproduction steps, the potential impact, and a minimal example when possible. We will acknowledge the report and follow up with an impact assessment and remediation plan.
